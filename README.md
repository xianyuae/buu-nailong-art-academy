# BUU奶龙艺术学院 · 交互画廊展览 (v5.0 全景真图层装配版)

本项目是专为“BUU奶龙艺术学院”打造的瑞士网格风格、野兽派与超现实主义全景交互式展览长页。

## 展览五幕叙事视觉系统 (v5.0)

1. **宏大全景五幕编排（Five-Act Seamless Interactive Journey $P \in [0.0, 5.0]$）：**
   - **作品一《思考者》**（$P \in [0.0, 1.0]$）：33 块几何图元构成的解构与聚合，暖羊皮纸色 **`#EFE6D8`**。
   - **作品二《守望者》**（$P \in [1.45, 2.0]$）：7 层野兽派空间进退景深，冷月灰 **`#CDD0D4`**。
   - **作品三《浮云原野》**（$P \in [2.45, 3.0]$）：全景破框铺满视窗，地平线与浮云对半舒展，深海岩石灰 **`#617173`**。
   - **作品四《苍翠秘境》**（$P \in [3.45, 4.0]$）：**与第三场景完全一致的全屏破框铺满视窗（100vw × 100vh）· 用户 Zip 7层真素材原件拼接装配 · 地板与两面玻璃墙三向汇聚装配 · 人物居中 · 零鼠标视差**：
     - **全景铺满**：严格像第三个场景一样，全景视窗铺满 `100vw × 100vh`，采用 `.fullscreen-depth-layer` 堆叠架构与纯正 `object-fit: cover`。
     - **Zip 原始7图层专属调配拼接 (`assets/layers_p4/layer_{1..7}.png`)**：
       - `layer_1.png`：天顶温室林野基底画纸大气层，沉稳垫底。
       - `layer_2.png`：赤陶地砖地板（由正下方滑入装配汇聚）。
       - `layer_3.png`：远景苍翠林野与晨曦天空（沉浸景深）。
       - `layer_4.png`：左面长虹玻璃立面与攀缘常春藤（由正左方滑入装配汇聚）。
       - `layer_5.png`：右面长虹玻璃立面与朝阳庭院（由正右方滑入装配汇聚）。
       - `layer_6.png`：中央转角结构中柱与天窗龙骨（锁扣入位）。
       - `layer_7.png`：奶龙主角，绝对居中定焦点拉焦，完全无位移。
     - **三向空间装配动效**：
       - **地板**：由下方 `dy: +180px` 向上滑动装配汇聚。
       - **左面玻璃墙**：由左方 `dx: -220px`、`rot: -5.0deg` 向右平移旋转合围。
       - **右面玻璃墙**：由右方 `dx: +220px`、`rot: +5.0deg` 向左平移旋转合围。
       - 随滚动推进（$P \in [3.45, 4.00]$）或点击“装配 ➔”按钮平滑聚合，装配完成达到 $100.00\%$ 像素级完美无缝拼合为单张全景图。
     - **人物严格居中**：主角奶龙在视窗中绝对保持在视觉中央（50.0% 水平，65.4% 垂直地面），微距拉焦（scale: 0.94 ➔ 1.00，blur: 6px ➔ 0px）。
     - **脱离鼠标晃动**：该页面彻底屏蔽鼠标视差微动，保持画面纯粹宁静的建筑定格感。
     - **流畅自然进退场**：进场（$P \in [3.05, 3.45]$）与退场（$P \in [4.05, 4.45]$）极为柔和自然，平滑转入下一幕纯白视频画布。
   - **作品五《跃动之躯》**（$P \in [4.45, 5.0]$）：**纯净无框融合巨幕影像**，至少占据视窗 1/3 以上，右下角方形悬浮静音控制与无缝时间轴，纯白画布 **`#FFFFFF`**。
